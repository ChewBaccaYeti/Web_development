Какая разница между методами paste, cat, join, split, expand и unexpand в UNIX системах?
А все просто:
'paste' - объединяет строки из разных файлов в один по горизонтале, можно установить префикс, суффикс и расстояние между словами в каждой строке.
'cat' - конкатенирует два и более файла или просто позвоялет просмотреть содержимое одного файла. В отличие от команды less, вывод можно продолжать до конца содержимого файла. Сшивает файлы по вертикали. 
'join' - работает с идентификаторами, при успешном результате проверки в одном из рядков файла, команда берет значения ID из двух или более файлов и сопостовляет их друг с другом в одном ряду. Таким образом имя человека и его запрлата будут стоять рядом. Также предусматривает различные виды манипуляций через флаги.
'split' - по дефолту разделяет огромный файл, скажем в 20 000 строк на 20 файлов по 1000 строк. Можно увеличить количество файлов до 40, уменьшив стандартное значение кол-ва строк на файл до 500. Можно устанавливать собственный суффикс именам разделеных файлов и тд.
'expand' - преобразовывает табуляцию в пробелы. Если нужен однородный файл или сжать текст кодового файла для транспортировки. По идее может сэкономить место.
'unexpand' - vice-versa предыдущего метода. Команда позволяет преобразовать пространстов между словами из пробелов в табуляцию. 
На деле два последних метода, как по мне, используются крайне редко, учитывая что есть линтеры и форматеры. Больше подходит для офисной монотонной работы.
